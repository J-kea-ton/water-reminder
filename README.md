# 喝水 & 站立 提醒

一个Mac菜单栏小程序。到点用系统通知提醒你喝水、站起来，专治久坐不喝水。

## 怎么用（第一次）

装一次就行，之后每天双击启动即可。

### 第一步：装一个依赖（只需一次）

打开"终端"（在"启动台"里搜"终端"或"Terminal"），把下面这行粘进去按回车：

```
/usr/bin/python3 -m pip install --user rumps
```

看到 `Successfully installed ... rumps` 就说明装好了。

### 第二步：启动

双击文件夹里的 **启动提醒.command**。

- 屏幕右上角（电量、WiFi那一排）会出现一个 💧 图标，就代表在运行了。
- 弹出来的黑色终端窗口可以直接关掉，不影响程序运行。

> 如果双击提示"无法打开，因为来自身份不明的开发者"：右键点这个文件 → 选"打开" → 再点"打开"。只需破例一次。

## 平时怎么操作

点右上角的 💧 图标，会看到菜单：

- **💧 喝水提醒：每 30 分钟（点击修改）** —— 点它，输入新的分钟数，回车保存
- **🧍 站立提醒：每 60 分钟（点击修改）** —— 同上
- **⏸ 暂停提醒** —— 开会/午休时不想被打扰就点它，图标会变成 💤；再点变回来
- **🔔 立即测试一次** —— 马上弹一条通知，检查提醒是否正常
- **退出** —— 关掉程序

改过的时间会自动记住，下次启动还是你设的值。

## 收不到通知怎么办

1. 先点菜单里的 **🔔 立即测试一次**。
2. 如果没弹出来：打开"系统设置" → "通知"，找到列表里的"脚本编辑器"（或 Script Editor / 终端），把通知打开，允许横幅提醒。

## 关掉程序

点 💧 图标 → **退出**。
