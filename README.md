# 爱上喝水

一只叫「柚柚」的桌面小云朵，陪你按时喝水。到点它会冒出来提醒你，屏幕上也会弹通知；点它一下就记一杯水。

Mac 桌面应用，桌宠常驻桌面，屏幕顶部菜单栏也有它，程序坞里也能找到——点系统通知可以直接跳到主面板。

## 怎么安装

1. 双击 `爱上喝水.dmg`（安装包）
2. 把里面的柚柚图标拖进「应用程序」文件夹
3. 去「应用程序」里双击「爱上喝水」打开

**第一次打开如果被系统拦住**（提示"来自身份不明的开发者"）：右键点图标 → 选「打开」→ 再确认一次「打开」。这一步只需做一次，之后正常双击即可。

需要 Apple 芯片（M 系列）的 Mac。

## 怎么用

- **记一杯水**：口渴喝完水，点桌面上的柚柚，气泡里点「喝了」，再选喝了多少——整杯 / 半杯 / 一小口 / 自定义。也可以打开面板直接点按钮记。
- **喝不满一杯**：选「自定义」，桌宠上会弹出滚轮，滚一下或直接输入毫升数，点「确定」记下。不用跳去别的窗口。
- **到点提醒**：柚柚按你设的间隔提醒。提醒时点「喝了」选量，点「待会儿」则 15 分钟后再提醒。**要是你两分钟没理它，它会自己按「待会儿」处理**，不会一直杵在桌面上。
- **看统计**：面板顶部点柱状图图标进「喝水统计」。能看近 7 天每天喝了多少、近 30 天的走势曲线，还有日均、连续达标天数、达标率。
- **看今天进度**：点柚柚身子选「打开面板」，能看到今天喝了多少、离目标还差多少，记错了可以点「刚才点错了」撤销。
- **改设置**：点屏幕最顶部菜单栏的柚柚图标 → 设置。能改提醒间隔、每天目标、杯子大小、活跃时段、免打扰时段、开机自启动等。
- **找不到柚柚了**：点顶部菜单栏的柚柚图标，能让它回来。

第一次打开会有个简单引导带你走一遍，跟着点就行（也能滑动翻页或跳过）。

### 它什么时候会提醒你

只在「该提醒」的时候才出声，不烦人：

- 只在你设的**活跃时段**内（默认 9:00–18:00），下班了就不催
- 距上次喝水满了**提醒间隔**（默认 60 分钟）才提醒，喝了就重新计时
- 今天**已经喝够目标**就不再催，柚柚照样醒着，还能继续记
- **暂停**和**免打扰时段**内不提醒

## 数据存在哪

你的喝水记录存在本机：`~/Library/Application Support/com.waterreminder.pet/state.json`，**不上传任何地方**。

每天零点开始新的一天，前一天的总量会存进历史（保留最近 30 天，供统计页使用）。

## 给开发者

技术栈：Tauri v2（Rust 后端 + 静态 HTML/CSS/JS 前端），无 Node、无构建步骤、无前端框架。

```bash
cd app/src-tauri
cargo tauri dev      # 开发模式运行
cargo tauri build    # 打包成 .app 和 .dmg
cargo test           # 跑单元测试
```

产物在 `app/src-tauri/target/release/bundle/` 下。

目录结构：

```
app/
  src/                  前端（三个窗口，各自一个单文件 HTML）
    main/               主面板：今日进度、记水、撤销
    pet/                桌宠：四状态、提醒气泡、自定义水量滚轮
    stats/              喝水统计：柱状图、趋势曲线、关键指标
    settings/           设置页
  src-tauri/
    src/main.rs         命令、托盘、提醒引擎、后台线程
    src/model.rs        Config / DayState / DayStat / AppState
    src/screenscan.rs   读其他 app 窗口位置（全屏藏边用）
    src/timeutil.rs     时间/日期工具
```

代码结构、实现要点、产品决策见 [CLAUDE.md](CLAUDE.md)。
