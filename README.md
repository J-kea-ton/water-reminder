# 爱上喝水

一只叫「柚柚」的桌面小云朵，陪你按时喝水。到点它会冒出来提醒你，屏幕上也会弹通知；点它一下就记一杯水。

Mac 桌面应用，安安静静待在桌面和屏幕顶部菜单栏，不占程序坞。

## 怎么安装

1. 双击 `爱上喝水.dmg`（安装包）
2. 把里面的柚柚图标拖进「应用程序」文件夹
3. 去「应用程序」里双击「爱上喝水」打开

**第一次打开如果被系统拦住**（提示"来自身份不明的开发者"）：右键点图标 → 选「打开」→ 再确认一次「打开」。这一步只需做一次，之后正常双击即可。

## 怎么用

- **记一杯水**：口渴喝水后，点桌面上的柚柚，弹出气泡点「喝了一杯」。也可以打开面板点按钮记。
- **到点提醒**：柚柚会按你设的间隔提醒。提醒时点「喝了」记一杯，点「待会儿」则 15 分钟后再提醒。
- **看进度**：点柚柚身子选「打开面板」，能看到今天喝了多少、离目标还差多少。
- **改设置**：点屏幕最顶部菜单栏的柚柚图标 → 设置。能改提醒间隔、每天目标、杯子大小、活跃时段、免打扰时段、开机自启动等。
- **找不到柚柚了**：点顶部菜单栏的柚柚图标，能让它回来。

第一次打开会有个简单引导带你走一遍，跟着点就行（也能滑动翻页或跳过）。

## 数据存在哪

你的喝水记录存在本机：`~/Library/Application Support/com.waterreminder.pet/state.json`，不上传任何地方。每天零点自动清零，开始新的一天。

## 给开发者

技术栈：Tauri v2（Rust 后端 + 静态 HTML/CSS/JS 前端），无 Node、无构建步骤。

```bash
cd app/src-tauri
cargo tauri dev      # 开发模式运行
cargo tauri build    # 打包成 .app 和 .dmg
cargo test           # 跑单元测试
```

产物在 `app/src-tauri/target/release/bundle/` 下。

代码结构、实现要点、产品决策见 [CLAUDE.md](CLAUDE.md)。
