## 0. 审美判断（B线：frontend-design）

这是产品UI/桌面工具（桌宠 + 内部进度页），不是营销页，走frontend-design。

**Design Thinking四问**

- Purpose：帮久坐上班族记得喝水的Mac桌面小工具。桌宠是唯一对外的提醒加确认入口，内部页是偶尔点开看今天喝够没的进度页。用户是零基础小白，产品是个人小工具，不堆功能。
- Tone：治愈系软陶（soft clay）。圆润、微立体、低饱和奶油底配清爽水蓝。刻意避开三个方向：高饱和糖果色（太幼稚）、粗黑描边贴纸卡通（太廉价）、玻璃拟态冷白蓝（太医疗、太套路）。用体积和柔和阴影表现可爱,而不是靠描边和高饱和,这是可爱但不幼稚的关键。
- Constraints：产物是SVG/HTML静态原型。桌宠是透明背景的漂浮小窗;内部页是约340px宽的Mac小窗口。中文界面。要满足对比度、点击尺寸、prefers-reduced-motion。
- Differentiation：记忆点是骨头勋章。喝水激励不用通用的星星或对勾,而用一枚狗骨头形状的勋章,把喝水成就和桌宠身份绑到同一个世界观里。光看题材猜不到这个app会用奶油棕小狗加骨头勋章加清爽水蓝,这就是context-specific character。

**Aesthetics五条**

- Typography：display用得意黑Smiley Sans（免费商用,圆润活泼有性格,用于大杯数和气泡强调）;正文用系统栈PingFang SC（中文补丁首选,零加载）。避开了Inter/Roboto作主字体。理由:得意黑是中文字体池里最活泼可爱的display,配系统栈正文中和动感,整体不过火。
- Color & Theme：奶油暖底 + 清爽水蓝主色 + 薄荷绿点缀 + 小狗奶油棕。避开紫渐变白底的AI俗套。色相收敛在蓝、绿、暖棕橙三种以内。理由:水蓝对应喝水语义天然贴切,暖底让整体温柔不冷。
- Motion：只在高冲击时刻用动画,水位上涨、勋章点亮、桌宠蹦出提醒、开心弹跳。不撒满整页微交互。理由:小工具打开时间短,动画集中在有反馈价值的瞬间。
- Spatial Composition：内部页垂直居中,杯子作主视觉;桌宠气泡从狗头一侧不对称冒出,不居中不呆板。
- Backgrounds & Visual Details：不用纯色平铺。内部页底用极淡奶油渐变加顶部一层很淡的水光晕;杯子有水的渐变和高光;软陶柔和长阴影用暖色不用纯黑。

**反AI套路自检（frontend-design条款,逐条过）**

1. 字体没踩Inter/Roboto/Arial作主字体。display是得意黑,正文中文用系统栈是cn_typography明确要求（西式字体不覆盖中文,系统栈是正文首选,不属于display禁令范围）。通过。
2. 配色没用紫渐变白底,用奶油底加水蓝。通过。
3. 布局不是三等分卡、不是Hero数字大屏、不是玻璃拟态默认、不是ghost-card。杯子居中加骨头勋章刻度条是这个题材的自然形态。通过。
4. 有context-specific character:骨头勋章、奶油棕小狗、达标光环,外人光看题材猜不到主色和风格家族。通过。

### 1.2 字体体系

```
--font-display: "Smiley Sans", "得意黑", "PingFang SC", sans-serif;
--font-body:    "PingFang SC", -apple-system, "HarmonyOS Sans SC", "MiSans", sans-serif;
--font-mono:    "JetBrains Mono", "PingFang SC", monospace;
```

- display（得意黑）:大杯数、页面标题、气泡里的强调词。中英混排西文和数字都走得意黑,统一。
- body（系统栈）:正文、按钮文字、标签、说明。
- mono:下次喝水的时间`15:30`、以后可能加的mL单位。数字走等宽,中文字体的数字不好看。

字号阶梯（在design_template基础上,按小窗口和大杯数需求微调,新增4xl给核心数字）

```
--text-xs:  11px  → 单位、时间戳
--text-sm:  13px  → 次级文字、标签、刻度节点名
--text-base:15px  → 正文、按钮文字
--text-lg:  17px  → 小标题、气泡提醒文案
--text-xl:  22px  → 达标鼓励文案、区域标题
--text-2xl: 30px  → 备用大标题
--text-4xl: 56px  → 今日杯数核心大数字（杯子上）
```

字重:正文400;标题和强调600;大杯数和达标文案700。得意黑本身偏粗,用于display时不再额外加粗到超700。同一段不超过3种字重。

### 1.3 间距体系（4px基准网格,照design_template）

```
--space-1:4  --space-2:8  --space-3:12  --space-4:16  --space-5:20
--space-6:24 --space-8:32 --space-10:40 --space-12:48 --space-16:64
```

用法:关联元素space-2到space-3;区块内段落space-4到space-6;区块之间space-8到space-12;窗口内边距space-6。

### 1.4 圆角体系（可爱风偏大圆角,按钮用药丸）

```
--radius-sm:  6px    → 小标签、超额+N药丸
--radius-md:  10px   → 次级按钮、信息块
--radius-lg:  16px   → 气泡、卡片
--radius-xl:  22px   → 窗口外框、杯子容器
--radius-full:9999px → 主按钮药丸、勋章圆底
```

### 1.5 阴影体系（软陶柔和阴影,用暖色不用纯黑）

```
--shadow-sm: 0 1px 2px  rgba(61,52,46,0.06);
--shadow-md: 0 4px 16px rgba(61,52,46,0.10);
--shadow-lg: 0 12px 32px rgba(61,52,46,0.14);
--shadow-glow-success: 0 0 0 6px rgba(47,176,124,0.18);   /* 达标光环 */
--shadow-glow-accent:  0 0 0 6px rgba(14,124,190,0.15);   /* 杯子聚焦 */
```

软陶体积感（桌宠身体、杯子）用一层内高光加一层柔和下投影表达,避免粗描边:内高光`inset 0 3px 6px rgba(255,255,255,0.5)`,配shadow-md下投影。

### 1.6 动效规范

```
--duration-fast:  150ms  → hover、颜色变化
--duration-normal:250ms  → 数字跳动、气泡展开
--duration-slow:  400ms  → 水位上涨、页面转场
--easing-default: cubic-bezier(0.4, 0, 0.2, 1);
--easing-spring:  cubic-bezier(0.34, 1.56, 0.64, 1);  → 弹跳、勋章点亮、桌宠蹦出
```

全局规则:可交互元素必有hover和active反馈;状态切换必有过渡不许瞬变;入场略慢出场略快;必须尊重`prefers-reduced-motion`,开启时关闭弹跳和水波,改为150ms淡入淡出。

## 2. 原型一:小狗桌宠形象

### 2.1 整体造型

- 品种气质:柴犬加拉布拉多幼犬的混合亲和感,简化成圆润几何。整体轮廓接近一颗圆润的豆子,没有尖锐边缘。
- 比例:幼态但不夸张。头身比约1:1（头略大一点),坐姿时整体轮廓接近一个圆角正方形。四肢短而圆,尾巴粗短。
- 线条风格:无描边或极细描边（描边细于1px或干脆不描）。体积靠色块加柔和内阴影加高光表现（软陶感）,不用粗黑描边。所有转角走圆角。
- 五官:圆眼睛用眼睛深棕加一小点白高光,不用纯黑;鼻子倒三角暖深棕;腮红两点珊瑚粉低透明,克制;嘴是一条柔和曲线。
- 待机尺寸:桌面漂浮时约110px见方（透明背景窗口,只有狗）。提醒蹦起时视觉高度可到128px,窗口相应放大以容纳上方气泡。

### 2.2 四个状态

每个状态给神态、姿势、可画的关键特征、循环动效,方便直接落成SVG加CSS。

**状态1 待机 idle**

- 神态:安静放松,眼睛正常睁开或微眯。
- 姿势:坐着,四肢收拢,尾巴自然垂放贴地。
- 关键特征:身体轮廓最圆最收拢;嘴闭合成平缓曲线;耳朵自然半垂。
- 循环动效:极轻微呼吸起伏,`scale 1 ↔ 1.02`,周期3.5s,easing-default。reduced-motion时静止。

**状态2 提醒 alert**

- 神态:兴奋招呼你,眼睛睁大发亮,嘴微张像在叫。
- 姿势:前腿抬起或整体蹦起,耳朵竖起,尾巴向一侧翘起并左右摇摆。
- 关键特征:身体比待机拉高一点（纵向拉伸感）;尾巴是独立可摆动的图层。
- 入场动效:从待机弹跳出现,`translateY`从下往上加`scale 0.9→1`,easing-spring,duration-slow。尾巴摇摆`rotate -12deg ↔ 12deg`,周期0.5s循环。
- 同时:一侧冒出提醒气泡（见2.3）。

**状态3 开心 happy**

- 神态:欢快,眼睛弯成月牙笑（`^ ^`）,嘴张开露出浅粉舌头。
- 姿势:原地跳一下或轻微转身,尾巴快速摇。
- 关键特征:头顶冒1到2个小装饰,水滴形或小爱心,向上飘散淡出;眼睛从圆眼切成弯月。
- 动效:确认喝了之后触发。整体弹跳一次`scale 1→1.12→1`加`translateY`小跳,easing-spring,duration-slow;头顶装饰上飘淡出。持续约1.2s后自动回到待机。
- 用途:点喝了的即时正反馈。

**状态4 暂停睡觉 sleep**

- 神态:安睡。
- 姿势:趴下,头枕在前爪上,眼睛闭合成两条下弯短线。
- 关键特征:鼻子上方冒一个飘动的Z或小气泡;整体饱和度较待机略降（叠一层约8%的冷灰,表示休眠）。
- 循环动效:Z字缓慢上飘淡出,周期2.5s;身体呼吸起伏比待机更慢更小。reduced-motion时Z静止。
- 触发:用户在菜单栏点暂停提醒时。

### 2.3 提醒气泡规格

- 位置:从小狗头部的右上方冒出,气泡下缘的小尖角指向狗头。不遮挡狗脸。若桌宠贴屏幕右边导致右上放不下,镜像到左上（实现时按屏幕位置翻转,设计默认给右上）。
- 形状:圆角矩形,`--radius-lg`(16px),背景`--color-bg-elevated`,阴影`--shadow-md`,底部一个约10px的小三角尾巴指向狗。
- 尺寸:宽约220px（下限200,上限240）;内边距`--space-4`(16px);高度随内容,提醒文案一行加按钮一行,约88到104px。
- 内容排布（从上到下两段）:
  1. 提醒文案:`--font-display`或body皆可,建议body,`--text-lg`(17px),`--color-text-primary`,单行,最多两行,居左。
  2. 两个按钮并排,间距`--space-2`(8px),各占约一半宽。

**气泡内按钮规格**

| | 喝了（主） | 待会儿（次） |
|---|---|---|
| 底色默认 | `--color-accent` | `--color-bg-tertiary` |
| 文字色 | 白（90%透明白,对比4.5:1达标） | `--color-text-secondary` |
| 圆角 | `--radius-full`药丸 | `--radius-full`药丸 |
| 高度 | 40px | 40px |
| 字号 | `--text-base`(15px) 600 | `--text-base`(15px) 400 |
| hover | 底色`--color-accent-hover`,`translateY(-1px)`,150ms | 底色加深到`#E9E1D3`,150ms |
| active | 底色`--color-accent-active`,`scale(0.97)` | `scale(0.97)` |
| disabled | 本场景无disabled态（气泡出现即两键可用） | 同左 |

按钮高度40px,两键间距8px,满足触控与相邻目标间距底线。

### 2.4 提醒文案候选

口语、简短、不油腻,遵守无AI腔。桌宠叫你喝水时,气泡里的一句从下面选或轮换:

- 该喝水啦
- 起来喝口水吧
- 水杯空着呢
- 喝水时间到咯
- 有点渴了,陪我喝一口

按钮文字固定:喝了 / 待会儿。

确认喝了之后的即时短反馈（可在气泡原位闪现0.8s或桌宠头顶飘一句,择一实现）:

- 记上啦
- 又一杯,不错
- 干得好

暂停后如需一句提示（可选,通常不显示）:安静一会儿,叫你时再见。

## 3. 原型二:app内部喝水页

在v1那版基础上改（v1那版是Mac小窗口,中间会涨水的杯子,下面今日几杯加一排小圆点进度加喝了一杯按钮加底部两个信息块）。本次改动清单:

1. 喝水杯数不设上限,新增每天一条达标线（默认8杯）。
2. 达标线之上继续喝、继续计数,杯子进入达标态并显示超额。
3. 用固定的里程碑刻度条替换v1那排会无限变长的每杯小圆点。
4. 里程碑勋章系统:4杯半程、8杯达标两个节点,点亮给鼓励。
5. 删掉这个页面里的站立提醒信息块（底部原来右边那块去掉）。
6. 保留下次喝水时间展示。
7. 每日自动清零。

### 3.1 布局结构

窗口:宽340px,高约480px,圆角`--radius-xl`(22px),背景`--color-bg-primary`叠一层顶部很淡的水光晕。自绘顶部条,不用原生标题栏。断点说明:这是固定小窗口,不做响应式多断点;正文字号已全部≥13px,大数字更大,移动端无关。

```
┌──────────────────────────────────┐  340×480  radius-xl  bg-primary
│  🐶  今天              7月12日     │  顶部条 height 52  内边距space-6
├──────────────────────────────────┤
│                                  │
│            ╭────────╮  ✨         │  杯子区 居中
│            │░░░░░░░░│             │  杯宽120 高156
│            │▓▓▓▓▓▓▓▓│             │  radius-xl容器
│            │████████│             │
│            ╰────────╯             │
│                                  │
```

### 3.2 组件规格清单

**A. 顶部标题条**

- 左侧:小狗头像icon（用桌宠idle脸,直径24px圆形）加文字今天,`--text-lg`600,`--color-text-primary`。
- 右侧:日期`7月12日`,`--text-sm`,`--color-text-secondary`,右对齐。
- 高度52px,底部不画分隔线,靠间距和背景分区。
- 无交互态（纯展示）。

**B. 水杯组件（核心,含水位、达标态、超额态）**

- 容器:宽120px高156px,杯身是上宽下略窄的圆角梯形玻璃杯,轮廓用`--color-border-default`极细描边（1px）,杯内透明,`--radius-xl`底角。
- 水:从杯底按比例填充,水位高度 = `min(今日杯数, 8) / 8` 的比例。水色上下渐变`--color-water-top`到`--color-water-bottom`,水面一条`--color-water-highlight`高光。
- 体积感:杯子右侧一道竖向白色高光条（约15%透明白）表现玻璃反光。
- 大杯数数字:叠在杯子正下方（不压在水面上,避免遮挡水位表达）,见组件C。
- 空状态（0杯）:杯子无水,杯底一句`--color-text-muted`小字提示今天还没喝水,喝第一杯吧。

杯子的三种视觉态:

| 态 | 触发 | 视觉 |
|---|---|---|
| 未达标 | 今日杯数<8 | 水位按比例,无光环 |
| 达标 | 今日杯数=8 | 水满到杯口;杯子外圈加`--shadow-glow-success`薄荷光环并呼吸脉动;杯口右上贴一枚8杯骨头勋章(已点亮);水色整体提亮一档 |
| 超额 | 今日杯数>8 | 保持达标态;杯子右上冒一个超额药丸标签,内容`+N`(N=杯数−8),底色`--color-success`subtle,文字`--color-success`,`--radius-sm`;水位维持满,靠光环脉动和药丸表达继续计数 |

达标不只靠颜色:同时有勋章图形加文字（今日X杯·已达标),颜色不是唯一信息载体,满足底线。

**C. 大杯数数字**

- 主数字:今日杯数,`--font-display`得意黑,`--text-4xl`56px 700,`--color-text-primary`。
- 副行:`今日 6 杯 / 达标 8`,`--text-base`,`--color-text-secondary`,达标线数字8可加`--color-success`。
- 达标后副行文案切换为`今天 X 杯 · 已达标`,达标二字用`--color-success`。
- 数字+1动效:旧数字向上淡出,新数字从下淡入并弹跳一下`scale 1→1.1→1`,easing-spring,duration-normal。

**D. 里程碑刻度条加勋章节点（替换v1的每杯小圆点）**

为什么换:杯数不封顶,每杯一个圆点会让进度条无限变长,超出固定窗口宽度,违反工程底线里长列表换组件不加长。改成宽度固定的里程碑刻度条,语义也更强。

- 结构:一条水平轨道,`--color-bg-tertiary`底槽,高6px,`--radius-full`;上面三个节点:起点、半程(4杯)、达标(8杯)。
- 进度填充:轨道上已达成部分用`--color-accent`填充,填充宽度按`min(今日杯数,8)/8`。
- 节点勋章:半程和达标两个节点是骨头形勋章,直径28px,圆底`--radius-full`。
  - 未点亮:灰底`--color-bg-tertiary`,骨头图形`--color-border-default`,空心感。
  - 半程点亮（≥4杯）:圆底`--color-warning`subtle,骨头`--color-warning`。
  - 达标点亮（≥8杯）:圆底`--color-success`subtle,骨头`--color-success`,外加一圈微光。
- 节点名:节点下方`--text-sm`,`--color-text-secondary`:起点、半程、达标。
- 点亮动效:达到杯数时对应勋章从灰切彩,`scale 0.6→1.15→1`弹跳加一圈光晕扩散淡出,easing-spring,duration-slow。同时触发达标鼓励横幅(组件F)。

**E. 主按钮 喝了一杯**

内部页保留的手动加一杯入口（沿用v1）。注意:桌宠点喝了和这个按钮点喝了都加到同一份今日计数,是同一个动作的两个入口,不重复累加。

| 态 | 规格 |
|---|---|
| 默认 | 底`--color-accent`,白字90%透明白(对比4.5:1),`--font-body` `--text-base`600,前面一个加号icon,药丸`--radius-full`,高44px,宽约200px居中,阴影`--shadow-sm` |
| hover | 底`--color-accent-hover`,`translateY(-1px)`,阴影升到`--shadow-md`,150ms |
| active | 底`--color-accent-active`,`scale(0.97)`,阴影回落 |
| disabled | 本产品无禁用场景(随时可加);若达标后想引导继续,按钮文案可切换为再来一杯,但仍可用,不置灰 |

按钮高度44px,满足触控底线。

**F. 达标鼓励横幅（达标瞬间出现的即时激励）**

- 触发:今日杯数首次达到4或8时,从窗口顶部滑入一条横幅,停留约2s后自动淡出上滑。
- 形状:圆角`--radius-lg`,4杯用`--color-warning`subtle底加`--color-warning`深字,8杯用`--color-success`subtle底加`--color-success`深字（subtle底加深字,不用饱和底加白字,保证对比）。
- 文案:4杯到了给喝到一半啦;8杯到了给今天达标,干得好。
- 动效:从上滑入,easing-spring,duration-normal;出场淡出上滑,duration-fast。reduced-motion时改纯淡入淡出。

**G. 下次喝水信息块（保留,站立块已删）**

- 位置:窗口底部居中,单个信息块（v1底部两块删掉站立那块,只剩这块）。
- 内容:标签下次喝水`--text-sm` `--color-text-secondary`,加时间`15:30` `--font-mono` `--text-lg` `--color-text-primary`。
- 形状:可做成一行居中纯文字,或一个`--color-bg-secondary`底、`--radius-md`的小卡片,内边距`--space-3`。
- 暂停状态:若用户在菜单栏暂停了提醒,这里文案切换为已暂停,时间处显示破折替代（用短横线字符,不用破折号符号),`--color-text-muted`。
- 无点击交互（纯展示,改间隔仍在菜单栏走）。

### 3.3 页面动效汇总

| 场景 | 动效 | duration / easing |
|---|---|---|
| 点喝了一杯,水位上涨 | 水面从当前高度升到新高度,水面波纹起伏一次 | `--duration-slow` / `--easing-default` |
| 杯数数字+1 | 旧数字上淡出,新数字下淡入弹跳 | `--duration-normal` / `--easing-spring` |
| 勋章点亮 | 灰切彩,弹跳加光晕扩散 | `--duration-slow` / `--easing-spring` |
| 达标鼓励横幅 | 顶部滑入停留淡出 | 入`--duration-normal`出`--duration-fast` / spring |
| 达标光环 | 薄荷光环缓慢呼吸脉动 | 循环2.5s |
| 按钮hover/active | 见组件E | `--duration-fast` |
| prefers-reduced-motion | 全部弹跳和水波关闭,改150ms淡入淡出;光环脉动停在静态 | — |

## 4. 设计依据（关键决策的为什么）

- 用奶油底加水蓝而非白底冷蓝:frontend-design的Color条,避开AI俗套冷白蓝和紫渐变,暖底更贴治愈陪伴气质。
- display选得意黑:cn_typography中文字体池里最活泼可爱且免费商用的display,满足frontend-design的Typography条要有性格,又避开系统默认宋体黑体。
- 正文用系统栈:cn_typography正文池首选,零加载,单机小工具不必背中文webfont的5到15MB。
- 骨头勋章而非通用星星:frontend-design的Differentiation,把激励和桌宠身份绑到一个世界观,形成记忆点。
- 每杯小圆点换成固定里程碑刻度条:工程底线长列表换组件不加长,杯数不封顶时每杯一点会撑破固定窗口宽度。
- 达标只用两个节点(4、8):任务要求别做复杂成就体系,两个当天节点足够给小激励。
- 主按钮accent取到#0E7CBE这个偏深的水蓝:工程底线正文对比≥4.5,白字要够深;清爽的亮水蓝留给不承载文字的杯中水。
- 达标和超额除颜色外都配图形加文字:工程底线颜色不作唯一信息载体。
- 桌宠气泡两按钮40px高、间距8px,主按钮44px高:工程底线触控尺寸与相邻目标间距。

## 5. 待决策项

1. 得意黑加载方式:静态原型若用得意黑做大数字,需本地装字体或引CDN,整包字体大,建议按cn_typography做子集化(标题字符量小,子集后通常小于200KB)。若渲染环境拿不到得意黑,回退到系统栈PingFang SC也能看,但会损失display的性格。请本体确认渲染环境能否提供得意黑。
2. 桌宠窗口形态:桌宠是透明背景可拖动的漂浮窗,还是先做成一个固定角落的简单方窗,属于技术实现选择。设计按透明背景漂浮给,若实现成本高可先落地方窗版,视觉规格不变。
3. 达标线是否可配:方案默认8杯写死。若要让用户改达标线(如6或10杯),里程碑半程节点需按达标线一半动态算。任务只说固定杯数比如8,默认写死,是否要做成可配请拍板。
4. 内部页手动喝了一杯按钮与桌宠确认的关系:两者加同一份计数,不重复累加。若产品上想让内部页只读、加水只走桌宠,可去掉这个按钮;当前按任务保留v1的按钮。请确认保留。
5. 清爽感与对比度的取舍:主交互色取了偏深的水蓝以保白字对比,视觉清爽度靠杯中水的亮水蓝补。若更想要通体清爽,可把主按钮改成浅水蓝底加深色字(而非白字),但会弱化按钮的主次感。当前选深底白字。
