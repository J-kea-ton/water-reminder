## 1. 一句话与范围

给久坐不喝水的上班族用的 Mac 桌面提醒小工具。核心是「提醒」；喝水打卡是让提醒真正生效的配套。本阶段只做喝水，站立提醒暂缓。

组成两块：

- **桌宠**：常驻桌面的透明浮窗，是对外的「提醒 + 打卡」主入口。
- **内部页**：偶尔点开看今天喝够没的进度页。

## 3. 打卡入口与按钮逻辑

三个入口，记同一份「今日杯数」，不重复累加；**任一入口 +1 都立即重置提醒倒计时**（计时记的是「距上次喝水多久」，不是「距上次提醒多久」）。

### 3.1 桌宠提醒气泡（到点自动弹）

| 按钮 | 点击后 |
|------|--------|
| 喝了 | 今日杯数 +1；重置提醒计时；桌宠转「开心」1.2s 后回待机；气泡关闭 |
| 待会儿 | 不加、不重置目标计时；气泡关闭；桌宠回待机；按当前间隔稍后再次提醒 |

### 3.2 桌宠待机主动气泡（点待机桌宠弹出）

| 按钮 | 点击后 |
|------|--------|
| 喝了一杯 | 今日杯数 +1；重置提醒计时；桌宠转「开心」；气泡关闭 |
| 打开面板 | 打开内部喝水页；气泡关闭 |

说明：点待机桌宠先弹气泡确认，不做「点一下直接 +1」，防手滑误加。首次使用弹一次性提示，告知待机点它能记一杯，并顺带一句「提醒频率能在设置里改」（原 ux 审查 M1，已补）。

### 3.3 内部页主按钮

| 按钮 | 点击后 |
|------|--------|
| ＋ 喝了一杯 | 今日杯数 +1；重置提醒计时；水位上涨；数字弹跳；触碰里程碑则点亮勋章 + 鼓励横幅；达标后文案变「今天喝得很足」，按钮文案可变「再来一杯」但仍可用 |

### 3.4 菜单栏（沿用 v1 的快捷操作）

| 项 | 逻辑 |
|----|------|
| 暂停 / 继续提醒 | 手动暂停：暂停期间桌宠转睡觉、不提醒；再点恢复并重新计时 |
| 立即测试一次 | 立刻弹一条提醒，供验证通知是否正常 |
| 设置… | 打开设置页 |
| 退出 | 关闭程序 |

**设置入口（原 ux 审查 B2，已补）**：设置页有两个入口。一是菜单栏「设置…」项，二是内部页顶部条右侧的齿轮图标。间隔、目标、时段等改动统一在设置页，不在菜单栏重复。

## 4. 提醒逻辑（聪明版）与时间设定逻辑

### 4.1 触发规则

同时满足三条才提醒：

1. 当前在**活跃时段**内（默认 09:00-18:00，可改）。
2. **距上次喝水 ≥ 提醒间隔**（默认 60 分钟，可改）。
3. 今天**尚未达标**（未到每日目标杯数）。

任一不满足则不提醒。达标 / 过了活跃时段 / 手动暂停 / 处于免打扰时段，都不提醒。

### 4.2 重置与频率

- 任一入口确认喝水 → 提醒计时清零重新数，下次提醒顺延。喝得越主动，提醒越少。
- 一天提醒次数不固定，由「目标杯数、活跃时段长度、间隔、你主动喝的量」共同决定，上限约为「活跃时长 ÷ 间隔」。

### 4.3 时间相关设定（都在设置页）

| 设定 | 默认 | 作用 | 备注 |
|------|------|------|------|
| 提醒间隔 | 60 分钟 | 距上次喝水多久该提醒 | 预设 30/45/60/90，± 微调，范围 15-180 |
| 活跃时段 | 09:00-18:00 | 只在这段时间提醒 | 起止可改 |
| 每日目标 | 8 杯 | 达到即达标、停止当天提醒 | 半程节点 = 目标一半 |
| 暂停提醒 | 关 | 手动一直暂停到你关掉 | 桌宠转睡觉 |
| 免打扰时段 | 未设 | 每天固定跳过提醒的时段（如午休 12:00-14:00），到点自动不提醒、过后自动恢复 | 不设=仅靠手动暂停 |
| 提示音 | 开 | 提醒时是否响一声 | |

「手动暂停」（一直停）与「免打扰时段」（每天定时跳过）是两件事，分两行。菜单栏的「暂停/继续提醒」与设置页的「暂停提醒」是同一个状态，双向同步显示（原 ux 审查 C4，已补）。

## 5. 内部喝水页逻辑

窗口约 340×500，海边度假风。自上而下：顶部条（水豚头像 + 今天 + 日期）→ 海边度假杯 → 大杯数 → 里程碑刻度条 → 喝了一杯按钮 → 下次喝水。站立块已删。

### 5.1 杯子三态

| 态 | 触发 | 表现 |
|----|------|------|
| 未达标 | 今日 < 目标 | 水位按 `今日/目标` 比例；水面动态水波 |
| 达标 | 今日 = 目标 | 水满近杯口；杯外薄荷光环脉动；达标勋章点亮；副行转「今天喝得很足」 |
| 超额 | 今日 > 目标 | 维持达标态；右上冒 `+N` 药丸（N=今日−目标，两位数直接显示）继续计数；**不再发新勋章、不再升级激励** |

原则：水喝够就行，不奖励越喝越多，激励在达标处收住。

### 5.2 里程碑与鼓励

- 固定三节点刻度条：起点、半程（目标一半，默认 4）、达标（默认 8）。用固定刻度条而非「每杯一个圆点」，因为杯数不封顶，每杯一点会撑破固定窗口。
- 勋章 = 柚子形。半程点亮（≥ 半程杯数）暖色柚子；达标点亮（≥ 目标）薄荷柚子加微光。
- 首次到 4 / 8 时，窗口顶部滑入鼓励横幅停约 2s：4 杯「喝到一半啦」；8 杯「今天达标，干得好」。达标后不再有新横幅。

### 5.3 其他

- 下次喝水（原 ux 审查 C2，已补）：正常显示下次提醒时间。其余场景各给对应文案，不显示不会兑现的时间：已达标显示「今天喝够啦」；免打扰时段内显示「午休中，HH:MM 后恢复」；活跃时段外显示「明天 HH:MM 见」；手动暂停显示「已暂停」。
- 每日清零（原 ux 审查 C5，已补）：第二天杯子归空、勋章重置、无历史、不算连续天数。当天第一次打开或清零发生时给一句轻提示「新的一天，喝起来」，避免用户以为昨天数据丢了。不做完整历史。
- 动态水波：双层正弦波（波幅 3px，前波 2800ms / 后波 3400ms）+ 最多 3 颗上升气泡；点喝了水位 400ms 升到新高度，波照常晃。

## 6. 桌宠状态机

切换标准 = app 当前状态：

| 状态 | 进入条件 | 表现 |
|------|----------|------|
| 待机 | 默认（没到点、没在庆祝、没休息） | 常驻桌面。呼吸 + 柚子微晃 + 随机眨眼 + 稀疏随机小动作（摇尾/歪头/哈欠/瞥你）。可点，点它弹主动打卡气泡 |
| 提醒 | 满足第 4.1 节三条触发 | 蹦起摆动招呼 + 提醒气泡（喝了 / 待会儿） |
| 开心 | 刚点了「喝了 / 喝了一杯」 | 眼弯月牙、蹦一下、头顶飘水花，约 1.2s 回待机 |
| 达标·满足（原 ux 审查 B1/C1，已改） | 今天已达标 | **不睡、仍常驻可点**。带满足感的待机（如叼着柚子、得意表情）。点它仍弹「喝了一杯」记超额，只是不再有主动提醒弹窗 |
| 睡觉 | 手动暂停 / 过了活跃时段 / 处于免打扰时段（**不含已达标**） | 闭眼、冒 Z、略降饱和 |

**睡觉态点击反馈（必须，非可选，原 ux 审查 C3，已改）**：睡觉态点击不记数，但必须给即时反馈。桌宠轻微抖一下并冒一个小气泡说明原因和恢复时机：手动暂停「在休息，点菜单栏可继续」；免打扰「午休中，14:00 恢复」；下班「下班啦，明早 9 点见」。不留「点了没反应」的空当。

呈现形式：透明背景浮窗，浮在桌面角落，可拖动，始终在最上层。

## 7. 设计逻辑

- **配色**：奶油暖底 `#FBF7F0` + 水蓝主色 `#0E7CBE`（白字对比 4.5:1）+ 薄荷绿达标 `#2FB07C` + 小水豚奶油棕 + 海边点缀（沙/珊瑚/柠檬/海蓝）。主强调色只用在按钮和达标高亮。
- **字体**：标题/大杯数用得意黑（活泼），正文用系统栈 PingFang SC（零加载）。中英混排西文在前。
- **圆角**：可爱风偏大圆角，按钮用药丸；卡片 16px，窗口 22px。
- **动效**：集中在高冲击时刻（水位上涨、勋章点亮、桌宠蹦出、开心弹跳、水波）。状态切换必有过渡不瞬变。
- **无障碍底线**：正文对比 ≥ 4.5:1；达标不只靠颜色（勋章图形 + 文字 + 光环三重）；可点目标 ≥ 44×44；尊重系统「减少动态效果」——开启时关闭水波/气泡/弹跳/呼吸，水位变化改 150ms 直接淡入，读数不变。

## 9. 待 ux-reviewer 重点看的流程（卡点自检提示）

- 三个打卡入口的一致性与可发现性（待机点桌宠这件事新用户是否知道）。
- 提醒被暂停 / 免打扰 / 达标 / 下班后，用户如何感知「现在不会提醒了」。
- 超额（>目标）时的反馈是否清楚、会不会让人以为没记上。
- 免打扰时段与手动暂停并存时，状态是否会让用户困惑。
- 桌宠睡觉态点击不记数时，是否给了「在休息」的反馈，避免用户以为点击失效。
