# 喝水提醒 v2 设计方案（第二轮 · 可爱角色重做 + 海边度假杯 + 动态水波）

- 日期：20260712
- 版本：v2 第二轮修订（在 `docs/ui-20260712-water-reminder.md` 基础上改，上一版保留做历史，本版为最新）
- 适用范围：桌面常驻桌宠 + app内部喝水进度页
- 交付对象：code-writer（照此稿用 SVG/HTML 渲染静态加动效原型）
- 审美线路：B线 frontend-design（产品UI桌宠，非营销页），沿用上一版已确立的治愈系软陶方向，本轮只调不推翻

## 0. 本轮改动概览

用户看过上一版后给了明确反馈，按下面七条改：

1. **形象不锁小狗，重做求更可爱**。给 4 个 chibi 幼态角色方向让用户挑，每个含造型/四状态/勋章形状/推荐度，全部能用 SVG 手绘落地。
2. **杯子换海边度假风**：高冷饮杯，杯口斜插柠檬片，配吸管，杯壁挂冷凝水珠。底线不变，水位是功能核心，柠檬吸管水珠是静态装饰，不盖过水位读数。
3. **杯中水做动态水波**：水面从静止直线改成轻晃的正弦波，加几个缓慢上升的小气泡；给足动效参数和 prefers-reduced-motion 降级。
4. **四个状态全动态，待机重点打磨**：待机是常驻桌面用户看得最多的样子，给呼吸加眨眼加随机小动作的循环方案，说清节奏和随机感。
5. **三个打卡入口 + 计时重置一致性**：主动打卡走点待机桌宠弹气泡确认，气泡和提醒态同一套 UI，本轮把这套气泡规格给全。
6. **配色往海边清爽靠一点**：奶油暖底加水蓝加薄荷不变，新增浅沙加珊瑚加柠檬黄加海蓝做点缀，不推翻。
7. **内部页其余**：杯数不封顶；4 杯半程、8 杯达标两个勋章节点；达标后只记数不加新奖励，文案转今天喝得很足；站立块已删；保留下次喝水时间；每日清零。

上一版的 token 结构（色彩/字体/间距/圆角/阴影/动效角色命名）、审美判断（软陶治愈、得意黑加系统栈、水蓝语义）、反 AI 套路自检结论全部沿用，本版只列改动，未列项默认继承 v1。

## 1. 设计语言（沿用 + 本轮调整）

### 1.1 沿用不变（照 v1 第 1 节）

- 全套 token 结构与角色命名照 v1 与 `~/.claude/rules/design_template.md`。
- 背景层级：`--color-bg-primary #FBF7F0` / `--color-bg-secondary #FEFCF8` / `--color-bg-tertiary #F2ECE1` / `--color-bg-elevated #FEFDFB`。
- 文字：`--color-text-primary #3D342E`（10.6:1） / `--color-text-secondary #7A6E62`（4.8:1） / `--color-text-muted #A89C8E`（仅用于大字或非关键信息）。
- 主强调水蓝：`--color-accent #0E7CBE`（白字 4.5:1 达标） / hover `#0C6DA8` / active `#0A5E92` / subtle `#E3F2FB`。
- 语义色：`--color-success #2FB07C`（subtle `#E4F6EE`） / `--color-warning #F5A623`（subtle `#FDF0D9`） / `--color-danger #E7614E`。
- 字体：display `--font-display: "Smiley Sans","得意黑","PingFang SC",sans-serif`；正文 `--font-body: "PingFang SC",-apple-system,"HarmonyOS Sans SC","MiSans",sans-serif`；等宽 `--font-mono: "JetBrains Mono","PingFang SC",monospace`。
- 字号阶梯：xs 11 / sm 13 / base 15 / lg 17 / xl 22 / 2xl 30 / 4xl 56。
- 间距 4px 网格、圆角（sm6 md10 lg16 xl22 full）、阴影（sm/md/lg 用暖色不用纯黑，加 glow-success / glow-accent）全部照 v1。

### 1.2 本轮新增 token（海边度假点缀色）

| token | 值 | 用途 |

| `--color-sand` | `#EFE1C6` | 浅沙，杯子落影、底部沙滩感点缀 |
| `--color-sand-subtle` | `#F7EFDD` | 更淡沙色，信息块底备选 |
| `--color-coral` | `#F98C6E` | 珊瑚，吸管条纹、装饰点缀、角色腮红 |
| `--color-coral-subtle` | `#FCE6DE` | 珊瑚低透明底 |
| `--color-lemon` | `#F4C13C` | 柠檬皮 |
| `--color-lemon-flesh` | `#FBEEAF` | 柠檬果肉 |
| `--color-sea` | `#1E88AC` | 海蓝，次级装饰（吸管弯头、深水影），比 accent 更清亮 |

### 1.3 杯中水装饰色（微调，往清爽提一档）

| token | 值 | 用途 |
|------|-----|------|
| `--color-water-top` | `#7FCEF0` | 水上部渐变（较 v1 提亮） |
| `--color-water-bottom` | `#3AA7E0` | 水下部渐变 |
| `--color-water-highlight` | `#CDEBFA` | 水面高光、气泡 |
| `--color-water-bubble` | `rgba(205,235,250,0.72)` | 上升气泡填充 |

### 1.4 本轮新增动效 token（水波与待机循环）

```
--duration-wave:    2800ms                       水面正弦波平移一循环
--duration-wave-2:  3400ms                       第二层波(不同周期,制造有机感)
--duration-bubble:  3600ms                       单颗气泡从杯底升到水面
--duration-breath:  3500ms                       待机呼吸一循环
--easing-linear:    linear                        水波与气泡连续动画
--easing-inout:     cubic-bezier(0.45,0,0.55,1)   呼吸起伏
```

沿用 v1 的 `--duration-fast 150 / normal 250 / slow 400`、`--easing-default`、`--easing-spring`。全局规则不变：可交互元素必有 hover 和 active 反馈；状态切换必有过渡不许瞬变；入场略慢出场略快；必须尊重 `prefers-reduced-motion`。

## 2. 角色方向（4 个，让用户挑）

统一硬约束（四个方向都遵守）：

- 走 chibi 幼态：大头、超大圆眼、软圆无尖角、腮红两点，可爱度拉满。
- 体积靠色块加柔和内高光加软陶下投影表现，无描边或极细描边（细于 1px），不用粗黑贴纸描边。
- 全部能用 SVG 手绘落地：形状简单，靠大眼睛和圆润取胜，不依赖精细插画笔触。
- 待机漂浮尺寸约 110px 见方（透明背景窗口，只有角色）；提醒蹦起视觉高度可到 128px，窗口相应放大容纳上方气泡。
- 每个方向自带一套勋章形状，随角色重定（替换 v1 的骨头勋章），用在内部页里程碑刻度条的 4 杯半程和 8 杯达标两个节点。
- 腮红统一 `--color-coral` 35% 透明两点；眼睛高光统一一小点 90% 透明白，眼睛主体用深色不用纯黑。

四个状态口径（切换标准照 CLAUDE.md）：待机是默认常驻态；提醒是到点满足触发条件；开心是刚点喝了后庆祝一两秒回待机；睡觉是暂停或下班时段或今天已达标。

### 2.1 方向 A：小水滴精灵（拟人水滴）

- **概念**：一颗会动的水珠精灵。app 是喝水提醒，主角就是水本身，看一眼就懂它管什么。
- **性格与记忆点**：单纯、黏人、随时想蹦。记忆点是通体清亮的水蓝身子加顶端一道翘起的小水花卷，像刚从杯里跳出来。
- **造型规格**：
  - 轮廓：一颗上尖下圆的水滴，顶端收一个小尖并往一侧微微卷起（水花卷）。头身一体，无脖子。
  - 比例：眼睛占身高约 45%，两只超大圆眼几乎占满脸，幼态拉满。
  - 配色：身子上下渐变 `#7FD0F2` 到 `#3FA9E5`，肚子处一片 `#DFF3FC` 淡高光；眼睛深墨蓝 `#24455A`；腮红珊瑚；短钝小手两只贴身两侧（可省）。
  - 五官：两只大圆眼加白高光，嘴一条小小上扬曲线，无鼻。
- **四状态**：

| 状态 | 神态与姿势 | 可画特征 |
|------|-----------|---------|
| 待机 | 安静微晃，眼正常睁 | 身子最圆最收，顶端水花卷轻摆 |
| 提醒 | 睁大眼蹦起招呼你 | 身子纵向拉高一点，顶端水花卷甩向一侧，两小手举起 |
| 开心 | 眼弯成月牙笑 | 头顶溅 1 到 2 个小水花点向上飘散淡出 |
| 睡觉 | 眯眼下沉发扁 | 身子压扁一档，顶端冒一个飘动的 Z，整体降约 8% 饱和 |

- **勋章形状**：水滴勋章。半程节点圆底加暖色水滴，达标节点圆底加薄荷水滴外一圈微光。
- **SVG 可行性**：最简，单一水滴 path 加两只眼加嘴，风险最低。
- **推荐度**：★★★★☆。最贴题、最好画，但水滴做水 app 吉祥物略常见，差异化中等。

### 2.2 方向 B：小水母（会漂的果冻）

- **概念**：一只软乎乎半透明的小水母，像果冻在水里漂。呼应喝水与海洋。
- **性格与记忆点**：轻飘飘、慢悠悠、爱发呆。记忆点是半透明伞盖加一圈短触手，待机时上下漂浮像泡在水里。
- **造型规格**：
  - 轮廓：上半个半透明圆顶伞盖，底下 4 到 5 根短而圆钝的波浪触手（简单曲线，不吓人）。
  - 比例：伞盖占身高约 60%，大眼长在伞盖正中偏下。
  - 配色：伞盖薄荷青 `#8FDBCE` 60% 半透明，顶部一片高光；触手同色更浅；眼睛深墨绿 `#2C4A44`；腮红珊瑚。
  - 五官：两只大圆眼加白高光，小圆嘴。
- **四状态**：

| 状态 | 神态与姿势 | 可画特征 |
|------|-----------|---------|
| 待机 | 慢漂发呆 | 整体上下浮动，触手随浮动柔摆 |
| 提醒 | 伞盖一鼓一收往上冲 | 伞盖脉动放大，触手向上收拢，眼睛发亮 |
| 开心 | 眼弯月牙，伞盖轻弹 | 头顶冒 1 到 2 个小气泡上升破掉 |
| 睡觉 | 沉底触手垂软 | 伞盖压扁，冒 Z，降约 8% 饱和 |

- **勋章形状**：海星勋章。半程暖色海星，达标薄荷海星加微光。
- **SVG 可行性**：伞盖简单，触手是唯一风险；限定 4 到 5 根圆钝曲线可控。
- **推荐度**：★★★☆☆。清爽有海洋感，触手让形状比水滴海豹稍复杂，可爱但不是最抱得住的那种。

### 2.3 方向 C：小海豹（圆滚滚）· 推荐

- **概念**：一只圆滚滚的小海豹，胖乎乎往那一趴。配海边度假杯是一整套海边世界观。
- **性格与记忆点**：憨、软、爱瘫。记忆点是几乎没有棱角的一坨身子加两只大黑圆眼，抱枕一样的存在感。
- **造型规格**：
  - 轮廓：一个横放的圆润胶囊（一坨），头和身一体，两侧两片小圆鳍。
  - 比例：眼睛占脸约 40%，两只又大又圆的深色眼是全角色最强幼态点。
  - 配色：身子鸽灰蓝 `#C9D8E2`，肚子奶白 `#FBFAF6`，眼睛近黑深灰 `#2B2621`（非纯黑），小圆鼻 `#3D342E`，腮红珊瑚，鼻两侧各三个小胡须点。
  - 五官：两只大圆眼加白高光，倒三角小鼻，嘴一条 W 形小曲线。
- **四状态**：

| 状态 | 神态与姿势 | 可画特征 |
|------|-----------|---------|
| 待机 | 安静趴着轻呼吸 | 身子最圆，两鳍贴身，偶尔一只鳍轻拍 |
| 提醒 | 抬头挺身两鳍举起招呼你 | 身子竖起一截，两鳍上抬左右摆，眼睛睁大发亮 |
| 开心 | 眼弯月牙，原地一弹 | 头顶飘 1 到 2 个小爱心或水花淡出 |
| 睡觉 | 侧趴闭眼 | 眼闭成两条下弯短线，鼻上冒 Z，降约 8% 饱和 |

- **勋章形状**：贝壳勋章（扇贝）。半程暖色扇贝，达标薄荷扇贝加微光。
- **SVG 可行性**：最省形状之一，一个胶囊加两片鳍加脸，几乎画不丑，幼态最稳。
- **推荐度**：★★★★★（本方案推荐）。

**推荐理由**：用户第一诉求是更可爱，海豹的圆滚一坨加超大黑圆眼是四个里幼态最稳、最抱得住的；形状最简单，SVG 手绘几乎不会翻车，正好对上要靠大眼睛和圆润取胜、不靠精细笔触的约束；它和本轮换的海边度假杯加贝壳勋章凑成一整套海边世界观，气质统一。要更贴水字面义就选 A 水滴精灵，要更有个性和当下热度就看 D 小水豚，但综合可爱度加落地稳度加与新杯子的世界观一致，海豹最优。

### 2.4 方向 D：小水豚（反差萌 · 头顶柚子）

- **概念**：一只佛系小水豚，头顶顶着一颗柚子。水豚爱泡水（泡温泉顶柚子是它的名场面），既沾水又是反差萌的那只大动物。
- **性格与记忆点**：极度 chill、不催不急、慢慢喝。记忆点是头顶那颗柚子加一脸没睡醒的淡定，一个从不唠叨的喝水搭子。
- **造型规格**：
  - 轮廓：一个圆角方砖形的暖棕一坨，顶两只小圆耳，头顶稳稳一颗柚子。
  - 比例：头身一体，眼睛比其他方向略小但仍放大成圆眼，配一脸平静。
  - 配色：身子暖棕 `#D8B489`，嘴口一片奶白 `#F6E9D6`，眼睛深棕 `#4A3B30`，腮红珊瑚，头顶柚子 `#F6A93B` 加一小片叶。
  - 五官：两只圆眼加白高光，小鼻小嘴，表情放空。
- **四状态**：

| 状态 | 神态与姿势 | 可画特征 |
|------|-----------|---------|
| 待机 | 放空发呆缓呼吸 | 身子最方最稳，头顶柚子随呼吸微晃，偶尔慢眨 |
| 提醒 | 慢半拍抬头看你 | 身子微起，耳朵轻动，柚子晃一下，眼睛睁大一点（不夸张，符合它 chill 人设） |
| 开心 | 眼弯月牙轻点头 | 头顶飘 1 到 2 个小水花淡出，柚子颤一下 |
| 睡觉 | 趴平闭眼 | 眼闭成短线，冒 Z，柚子稳在头顶，降约 8% 饱和 |

- **勋章形状**：柚子勋章（小圆果加一片叶）。半程暖色柚子，达标薄荷柚子加微光。
- **SVG 可行性**：一个圆角方块加两耳加头顶圆果，简单可控。
- **推荐度**：★★★★☆。当下最有话题度、个性最强、佛系人设正好配一个不唠叨的喝水提醒；比海豹稍复杂一点点（多了耳朵和柚子），但差异化最高。

## 3. 海边度假杯规格（替换 v1 玻璃杯）

坐标约定：杯身本地坐标原点在杯身外框左上角，杯身外框宽 100，高 196。杯口 rim 在 y=0，杯底在 y=196。装饰件坐标都相对这个框给。

### 3.1 杯身（高冷饮杯）

- 杯型：高身微收的 highball 冷饮杯，上宽下略窄。杯口外宽 100，杯底外宽 84，高 196。杯底两角圆角 14px，杯口两角圆角 6px。
- 玻璃：杯壁 1.5px 极细描边，色 `--color-border-default` 降到约 60% 透明；杯内透明叠一层极淡水蓝 `rgba(127,206,240,0.06)` 表示空杯也是凉饮玻璃。
- 玻璃反光：杯身左侧一道竖高光条，宽 12px，15% 白，从 y=14 到 y=182，圆头。
- 落影：杯底下方一片 `--color-sand` 20% 透明的椭圆软影，宽 96 高 14，表现放在桌面的清凉感。

### 3.2 水位（功能核心，优先级最高）

- 水从杯底按比例填充，水位高度 = `min(今日杯数,8) / 8 × 可填充高度`。可填充区从 y=180（近杯底留一点玻璃厚度）到 y=8（近杯口留一点空隙）。
- 水色上下渐变 `--color-water-top` 到 `--color-water-bottom`，水面是动态正弦波（见第 4 节），不是直线。
- 空状态（0 杯）：无水，杯底居中一句 `--color-text-muted` 小字今天还没喝水，喝第一杯吧。
- 底线执行：柠檬吸管水珠三件装饰全部安排在杯口以上或杯壁外沿，不覆盖杯内水柱中段（1 到 7 杯的水位读数区），保证任何时候水位一眼可读。

### 3.3 柠檬片（静态装饰）

- 位置：斜插挂在右侧杯口。柠檬中心约 (x=80, y=-2)，直径 46，一半在杯口以上一半搭在杯口内沿，倾斜 -18deg。它落在杯口最上沿，只在水满到杯口时轻叠水面顶端，不遮中段水位。
- 造型：一片圆柠檬横切面。外圈皮 `--color-lemon` 宽约 5px，内圈果肉 `--color-lemon-flesh`，中心到边 6 到 8 条细放射分瓣线用 `--color-lemon` 40% 透明。
- 无描边或极细描边，圆润。

### 3.4 吸管（静态装饰）

- 位置：从饮品里斜插出杯口左上。杯内段底端约 (x=40, y=150)，斜向左上，穿出杯口在 (x=32, y=0)，继续到杯口上方 (x=16, y=-46)，顶端一个短弯头（弯向左）。整体倾斜约 14deg。
- 规格：宽 8px，圆头。珊瑚白斜条纹（`--color-coral` 与白交替，条纹宽约 6px），弯头处一小段 `--color-sea` 提清凉。
- 杯内段透过玻璃与水做半透明叠加（约 70% 不透明），保持通透。

### 3.5 冷凝水珠（静态装饰）

- 位置：贴在杯壁外沿左右两侧的中下部，避开杯内水柱中段读数。建议 5 颗：(x=14,y=96,r=3.5)、(x=18,y=132,r=5)、(x=26,y=158,r=4)、(x=86,y=112,r=6)、(x=90,y=146,r=4)，坐标都在杯身边缘一带。
- 造型：椭圆小水珠，填充 `--color-water-highlight` 55% 透明，右上角一点白高光，做出挂在冰凉玻璃上的凝水感。
- 全部静态，不参与动画（reduced-motion 与常态一致）。

装饰件层级从下到上：落影 → 杯壁描边 → 杯内水（含动态波与气泡）→ 玻璃反光条 → 冷凝水珠 → 吸管 → 柠檬片。柠檬和吸管压在最上是因为它们在杯口以上，不影响水柱可读。

## 4. 动态水波规格

目标：水面轻轻起伏像在晃，加几颗缓慢上升的小气泡，全部 SVG path 动画可落地，且不抢水位读数。

### 4.1 水体结构（SVG 实现思路）

- 水体是一个 `<path>` 填充：左右两条竖边贴杯内壁，底边贴杯底，顶边是一条正弦波曲线。用 `<clipPath>` 把水体裁进杯身内轮廓，防止溢出杯壁。
- 水面波用两层叠加做出有机不呆板的晃动：
  - 前波：不透明度 100%，用水渐变色。
  - 后波：不透明度约 45%，相位比前波偏移半个波长，颜色 `--color-water-highlight`，做出水面反光层次。
- 波形 path 画成杯宽两倍（约 200 单位）里含 3 个完整正弦波，然后整条 path 沿 x 轴平移循环，从 `translateX(0)` 到 `translateX(-100)`（即移动一个杯宽），首尾无缝衔接，形成持续流动。

### 4.2 波参数

- 波幅（振幅）：3px（峰谷各 1.5px）。刻意小，读作轻晃不是波涛，不干扰水位判断。
- 波长：杯内宽度约含 1.5 个完整波（前波），后波同波长错半相位。
- 平移周期：前波 `--duration-wave` 2800ms 线性循环，后波 `--duration-wave-2` 3400ms 线性循环。两层周期不同，叠加后不会周期性完全重合，看着更自然。
- 水位变化时：点喝了一杯，水面整体从旧高度升到新高度用 `--duration-slow` 400ms `--easing-default`，升的过程中波照常晃，到位后继续常态晃动。

### 4.3 上升气泡

- 数量：同时最多 3 颗在途。
- 尺寸：直径 3 到 5px 随机。
- 颜色：`--color-water-bubble`，右上一点白高光。
- 轨迹：从水体底部随机 x 位置生成，垂直上升到水面附近（升到距水面约 6px 处）淡出消失，单颗历时 `--duration-bubble` 3600ms 线性。
- 节奏与随机：每约 1.5s 冒一颗，出生 x 位置在杯宽内随机，上升途中带极轻微左右摆（±1.5px，正弦），避免机械直线。水位越高（喝得越多）可略微提高冒泡频率到每 1.1s 一颗，做一点越喝越有气的暗示（可选，非必需）。

### 4.4 prefers-reduced-motion 降级

- 水面波：冻结为一条静止的水面线（停在正确水位高度，可保留极轻一道弧度显得不生硬），不再平移。
- 气泡：全部隐藏，不生成。
- 水位变化：仍要发生（点喝了水位要涨），但改为 150ms 直接淡入到新高度，不做涨水过程动画。
- 结论：降级后水位读数与常态完全一致，只是不动。

## 5. 待机与四状态动效（待机重点打磨）

四个状态切换标准照 CLAUDE.md：待机默认；提醒满足触发条件；开心点喝了后一两秒；睡觉暂停或下班或已达标。下面动效对选定角色通用，姿势细节看第 2 节各角色的四状态表。

### 5.1 待机 idle（常驻桌面，看得最多，重点）

待机不能呆，用三层叠加做出活但不闹：

- **第一层 呼吸（常驻）**：整体 `scale 1 ↔ 1.03`，纵向为主，周期 `--duration-breath` 3500ms，`--easing-inout`。软陶身子随呼吸有极轻起伏，一直在。
- **第二层 眨眼（随机）**：眼睛快速闭合再睁开，闭合 120ms。触发间隔在 4 到 7s 之间随机取值，偶尔连眨两下（约 15% 概率），像真的在发呆。
- **第三层 小动作（随机稀疏）**：每隔 8 到 14s 随机触发一个小动作，从动作池里随机选一个，播完回待机基态：
  - 摇尾或拍鳍：尾巴或一只鳍 `rotate ±12deg` 摆两下，0.6s（海豹拍鳍、水滴摆水花卷、水母摆触手、水豚动耳，各自替换成对应部位）。
  - 歪头：整体 `rotate 0 → 6deg → 0`，0.8s，`--easing-inout`。
  - 打哈欠：嘴张开成小圆再合上，配一次深呼吸放大，1.0s。
  - 瞥你一眼：眼睛（或高光点）向一侧移一点再移回，0.7s，像瞄了下用户。

- **随机感怎么做**：不要固定顺序轮播。用一个计时器，每次随机取 8 到 14s 的间隔，到点从动作池随机抽一个；给常见温和动作（歪头、瞥你）更高权重，打哈欠这类低频（权重减半），避免老是打哈欠。眨眼独立计时，与小动作互不同步，两条随机线交错，整体就没有可预测的节拍。
- **reduced-motion**：呼吸、小动作、水波全停，角色定在待机基态；眨眼可保留但降到很低频（每 8 到 12s 一次）或一并停掉，取其一。

### 5.2 提醒 alert

- 从待机弹跳出现：`translateY` 从下往上加 `scale 0.9 → 1`，`--easing-spring`，`--duration-slow`。
- 循环招呼动作：对应部位（鳍/手/触手/耳加柚子）左右摆 `rotate -12deg ↔ 12deg`，周期 0.5s，直到用户处理气泡。
- 同时一侧冒出提醒气泡（见第 6 节）。
- reduced-motion：去掉弹跳与摆动，改 150ms 淡入到提醒姿态，气泡淡入。

### 5.3 开心 happy

- 点喝了后触发：整体弹跳一次 `scale 1 → 1.12 → 1` 加 `translateY` 小跳，`--easing-spring`，`--duration-slow`；眼睛切成弯月笑；头顶飘 1 到 2 个角色对应小装饰（水花/爱心/气泡）上飘淡出。
- 持续约 1.2s 自动回待机。
- reduced-motion：去弹跳，仅眼睛切弯月加头顶装饰淡入淡出，约 0.8s 回待机。

### 5.4 睡觉 sleep

- 触发：菜单栏暂停、下班时段、今天已达标，任一进入睡觉态。
- 姿势：趴下闭眼（各角色见第 2 节表），鼻上方冒一个缓慢上飘淡出的 Z，周期 2.5s；整体叠约 8% 冷灰表示休眠；呼吸比待机更慢更小（周期拉到约 4.5s）。
- reduced-motion：Z 静止或隐藏，呼吸停，定在睡姿。

### 5.5 状态切换总原则

- 状态之间切换用 250ms 交叉淡入淡出打底，再叠各状态自己的入场动作。
- 达标进入睡觉是得意加安睡的组合：可先播一个开心弹跳再淡入睡觉态。
- 入场略慢出场略快，全程尊重 reduced-motion。

## 6. 打卡气泡规格（提醒态与主动态共用一套 UI）

三个打卡入口里，提醒态弹气泡和主动打卡（点待机桌宠）弹气泡用同一套气泡外壳，只有文案和按钮内容按场景换。第三个入口是内部页的喝了一杯主按钮（见第 7 节组件 E）。任一入口 +1 都记同一份今日计数，且都要立即重置提醒倒计时（计时记距上次喝水多久，不是距上次提醒多久），这条是逻辑一致性，实现时三条路都要重置，不能只给提醒这条路。

### 6.1 气泡外壳（两种场景共用）

- 位置：从角色头部右上方冒出，气泡下缘小尖角指向角色，不遮脸。若桌宠贴屏幕右边导致右上放不下，镜像到左上（实现按屏幕位置翻转，设计默认给右上）。
- 形状：圆角矩形 `--radius-lg` 16px，背景 `--color-bg-elevated`，阴影 `--shadow-md`，底部约 10px 小三角尾巴指向角色。
- 尺寸：宽约 220px（下限 200 上限 240），内边距 `--space-4` 16px，高度随内容，约 88 到 104px。
- 内容两段（上下）：第一段文案，`--font-body` `--text-lg` 17px `--color-text-primary`，居左，最多两行；第二段两个按钮并排，间距 `--space-2` 8px，各占约一半宽。
- 出入场：从角色一侧弹出 `scale 0.9 → 1` 加轻微 `translateY`，`--easing-spring` `--duration-normal`；关闭淡出上滑 `--duration-fast`。reduced-motion 改纯淡入淡出。

### 6.2 场景一 提醒态气泡（到点自动弹）

- 文案（轮换取一）：该喝水啦 / 起来喝口水吧 / 水杯空着呢 / 喝水时间到咯 / 有点渴了陪我喝一口。
- 两按钮：喝了（主）、待会儿（次）。
- 行为：喝了 = 今日 +1 并重置计时、桌宠转开心态、气泡关闭；待会儿 = 不加、稍后再提醒、气泡关闭。

### 6.3 场景二 主动态气泡（点待机桌宠弹）

- 文案：记一杯吗（备选：喝了一杯吗）。
- 两按钮：喝了一杯（主，= 今日 +1 并重置计时，桌宠转开心态）、打开面板（次，= 打开内部喝水页，气泡关闭）。
- 设计定为点桌宠先弹气泡确认，不做点一下直接 +1，防手滑误加。

### 6.4 气泡内按钮四态（两场景通用）

| | 主按钮（喝了 / 喝了一杯） | 次按钮（待会儿 / 打开面板） |
|---|---|---|
| 默认 | 底 `--color-accent`，白字 90% 透明白（4.5:1 达标），`--text-base` 15px 600，药丸 `--radius-full`，高 40px | 底 `--color-bg-tertiary`，字 `--color-text-secondary`，`--text-base` 15px 400，药丸 `--radius-full`，高 40px |
| hover | 底 `--color-accent-hover`，`translateY(-1px)`，150ms | 底加深到 `#E9E1D3`，150ms |
| active | 底 `--color-accent-active`，`scale(0.97)` | `scale(0.97)` |
| disabled | 本场景无 disabled（气泡出现即两键可用） | 同左 |

两键高 40px、间距 8px，满足触控尺寸与相邻目标间距底线。

### 6.5 首次使用一次性提示

- 触发：用户第一次让桌宠常驻后（或第一次待机态出现时），一次性冒一个引导气泡，之后不再出现。
- 外壳同 6.1，单段文案无按钮（或右上一个知道啦小关闭），点任意处或几秒后自动收起。
- 文案：想起来喝水就点我一下，帮你记一杯。
- 目的：告诉用户待机点桌宠能主动记一杯。

### 6.6 确认后的即时短反馈（开心态可选叠加）

- 点喝了或喝了一杯后，除桌宠转开心态，可在气泡原位闪现一句 0.8s 或桌宠头顶飘一句，择一实现。
- 文案（取一）：记上啦 / 又一杯不错 / 干得好。

### 6.7 桌宠作为可点击对象的四态

| 态 | 规格 |
|---|---|
| 默认 | 待机循环动效（第 5.1 节），cursor pointer |
| hover | 整体 `scale(1.05)` 加轻微提亮，150ms，暗示可点 |
| active | 按下 `scale(0.96)`，随即弹出主动态气泡 |
| disabled | 睡觉态（暂停 / 下班 / 已达标）时点击不弹打卡气泡；可给一个轻微摆动加一个静态 Z 提示在休息，不记数不重置 |

  - 达标点亮（≥8 杯）：圆底 `--color-success` subtle，勋章 `--color-success`，外加一圈微光。
- 节点名：下方 `--text-sm` `--color-text-secondary`：起点、半程、达标。
- 点亮动效：达到杯数时对应勋章灰切彩，`scale 0.6 → 1.15 → 1` 弹跳加光晕扩散淡出，`--easing-spring` `--duration-slow`，同时触发鼓励横幅（组件 F）。

**E. 主按钮 喝了一杯（第三个打卡入口，四态）**

| 态 | 规格 |
|---|---|
| 默认 | 底 `--color-accent`，白字 90% 透明白（4.5:1），`--font-body` `--text-base` 600，前置加号 icon，药丸 `--radius-full`，高 44px，宽约 200px 居中，阴影 `--shadow-sm` |
| hover | 底 `--color-accent-hover`，`translateY(-1px)`，阴影升 `--shadow-md`，150ms |
| active | 底 `--color-accent-active`，`scale(0.97)`，阴影回落 |
| disabled | 无禁用场景（随时可加）；达标后文案可切再来一杯但仍可用不置灰 |

点此加一杯与桌宠打卡加同一份今日计数，不重复累加，且同样重置提醒倒计时。高 44px 满足触控底线。

**F. 鼓励横幅（4 杯与 8 杯节点即时激励）**

- 触发：今日杯数首次达到 4 或 8 时，从窗口顶部滑入，停约 2s 后淡出上滑。
- 形状：圆角 `--radius-lg`，4 杯用 `--color-warning` subtle 底加 `--color-warning` 深字，8 杯用 `--color-success` subtle 底加 `--color-success` 深字（subtle 底加深字保证对比，不用饱和底加白字）。
- 文案：4 杯给喝到一半啦；8 杯给今天达标，干得好。达标之后不再有新横幅，超额只在副行显示今天喝得很足。
- 动效：入场从上滑入 `--easing-spring` `--duration-normal`，出场淡出上滑 `--duration-fast`，reduced-motion 改纯淡入淡出。

**G. 下次喝水信息块（保留，站立块已删）**

- 位置：窗口底部居中，单个信息块。
- 内容：标签下次喝水 `--text-sm` `--color-text-secondary` 加时间 15:30 `--font-mono` `--text-lg` `--color-text-primary`。
- 形状：一行居中纯文字，或 `--color-bg-secondary` 底 `--radius-md` 小卡片内边距 `--space-3`。
- 暂停态：文案切已暂停，时间处用短横线字符替代，`--color-text-muted`。
- 无点击交互（改间隔仍在菜单栏走）。

| 场景 | 动效 | duration / easing |

## 8. 设计依据（关键决策的为什么）

- 角色重做走 chibi 幼态且优先水主题：对应用户第一诉求更可爱，water 主题最贴题且形状最简单，符合 frontend-design 要有 context-specific character 又靠圆润取胜的约束。
- 推荐小海豹：四个里幼态最稳、SVG 最不易翻车，且与本轮换的海边度假杯加贝壳勋章凑成统一海边世界观，气质一致。
- 勋章随角色重定：延续 v1 骨头勋章绑桌宠身份的记忆点思路（frontend-design 的 Differentiation），换角色后把激励图形也换成贴新角色的形状，维持世界观一致。
- 杯子换高冷饮杯加柠檬吸管水珠：CLAUDE.md v2 明确要求，看着就想喝水；同时把装饰全压在杯口以上或杯壁外沿，守住水位是功能核心的底线。
- 水面改正弦波加气泡：让常驻画面更有生气；波幅压到 3px 是为了晃而不抢读数；双层不同周期避免机械重复。
- 待机三层叠加加随机：待机是常驻看得最多的样子，呼吸打底加随机眨眼加稀疏随机小动作，用两条不同步的随机线消除可预测节拍，避免呆滞。
- 里程碑刻度条替代每杯圆点：工程底线长列表换组件不加长，杯数不封顶时每杯一点会撑破固定窗口。
- 达标后文案转今天喝得很足只记数：CLAUDE.md v2 明确奖励在达标收住，水喝够就行不奖励越喝越多。
- 主交互色仍取偏深水蓝 `#0E7CBE`：工程底线白字对比 ≥4.5，清爽感靠杯中水提亮和度假点缀色补，不靠调亮按钮。
- 达标与超额除颜色外都配图形加文字：工程底线颜色不作唯一信息载体。
- 气泡两按钮 40px 高间距 8px、主按钮 44px 高：工程底线触控尺寸与相邻目标间距。

## 9. 待决策项

1. **选哪个角色**：本方案推荐小海豹（C），备选水滴精灵（A，最贴水字面义）、小水豚（D，个性与热度最高）、小水母（B，海洋清爽但触手略复杂）。请用户拍板，选定后勋章形状、顶部头像、各状态姿势随之定死。
2. **得意黑加载方式**（沿用 v1 待决）：大数字用得意黑需本地装字体或引 CDN，整包大，建议按 cn_typography 子集化（标题字符量小，子集后通常小于 200KB）。渲染环境拿不到得意黑则回退系统栈 PingFang SC，会损失 display 性格。请确认渲染环境能否提供。
3. **桌宠窗口形态**（沿用 v1 待决）：透明背景可拖动漂浮窗，还是先做固定角落方窗，属技术实现选择。设计按透明漂浮给，落地成本高可先做方窗版，视觉规格不变。
4. **达标线是否可配**：默认 8 杯写死，半程节点取一半为 4。若要让用户改达标线，半程需按达标线一半动态算。任务只说固定，默认写死，是否可配请拍板。
5. **气泡越喝越多的冒泡加速**（第 4.3 节可选项）：水位高时略提高冒泡频率，是锦上添花，若嫌复杂可去掉，气泡恒定节奏也够用。请确认要不要。

- **反 AI 套路自检（frontend-design 条款，逐条过）**：
  1. 主字体没踩 Inter/Roboto/Arial，display 得意黑，正文中文用系统栈（cn_typography 明确正文首选）。通过。
  2. 配色没用紫渐变白底，用奶油底加水蓝加海边点缀。通过。
  3. 布局非三等分卡、非 Hero 数字大屏、非玻璃拟态默认、非 ghost-card，杯子居中加里程碑刻度条是题材自然形态。通过。
  4. 有 context-specific character：可爱角色加对应勋章加海边度假杯，外人光看题材猜不到会用小海豹加贝壳勋章加冷饮杯。通过。
- **实施注意与坑**：
  1. 水位是功能核心，柠檬吸管冷凝珠三件装饰必须安排在杯口以上或杯壁外沿，任何情况不覆盖杯内水柱中段读数。
  2. 水波波幅锁 3px，别为了显眼调大，调大会干扰水位判断；双层波要用不同周期（2800 与 3400）避免机械重复。
  3. 待机的随机感靠两条不同步随机线（眨眼一条、小动作一条）加随机间隔加随机抽动作，不要写成固定顺序轮播，否则又会呆。
  4. 主按钮和气泡主按钮的白字对比依赖 accent 取到 `#0E7CBE` 这个深度，不要为了清爽调亮，调亮破对比度。
  5. 里程碑刻度条固定三节点，勋章形状随所选角色，不要退回每杯一个圆点，否则杯数不封顶会撑破窗口。
  6. 达标与超额必须同时给图形加文字加光环，不能只靠颜色。
  7. 三个打卡入口（提醒气泡喝了、主动气泡喝了一杯、内部页喝了一杯按钮）加同一份计数不重复累加，且三条路都要重置提醒倒计时，别只给提醒这条路重置。
  8. 所有弹跳、水波、气泡、呼吸、小动作都要包 `prefers-reduced-motion` 降级，降级走 150ms 淡入淡出，水位变化仍发生只是不做过程动画。
  9. 桌宠四状态与内部页所有可交互元素的默认/hover/active/disabled 四态已在文档各处给全。
  10. 中文与数字之间不加空格，文案候选照抄，不要改成油腻长句。
- **A线提醒不适用**：本项目走 B线产品 UI，不涉及 taste-skill 营销动效骨架；中文字体已按 cn_typography 处理。
