# 喝水提醒主页面布局重设计方案

- 日期：20260717
- 适用范围：app主页面（`app/src/main/index.html`），固定340x620px窗口
- 交付对象：code-writer
- 审美线路：B线 frontend-design（产品UI），沿用项目已建立的治愈系暖色方向

## 2. 审美方向（B线 frontend-design）

### Design Thinking四问

- **Purpose**：喝水提醒app的主面板，给久坐上班族看今天喝了多少水、快速记一杯。使用场景是工作间隙瞟一眼或被提醒后点一下，停留时间短（3-5秒）
- **Tone**：温暖治愈（warm & nurturing），项目已确立的方向。杯子海边度假风+水豚柚柚桌宠构成统一世界观。不是工具感，是陪伴感
- **Constraints**：340x620固定窗口、不可滚动、Tauri v2 webview渲染、已有色彩体系和组件样式不可改
- **Differentiation**：度假风杯子的水面动画是别的喝水app没有的视觉记忆点。用户记住的是那杯晃动的水和头顶柚子的水豚

### Aesthetics Guidelines五条决策

1. **Typography**：正文用系统栈（项目既有决策，cn_typography.md明确正文首选系统栈零加载成本）。大数字是页面唯一需要展示字体的地方，v2文档定了得意黑但当前页未加载（见待决策项）
2. **Color & Theme**：暖奶油底`#FBF7F0`配水蓝强调`#0E7CBE`，成功绿`#2FB07C`做达标语义色。三色收敛，不动。水蓝只出现在主按钮和进度填充两处，占比约8%
3. **Motion**：集中在水面波浪动画（常驻、是视觉核心）和水位上涨（操作反馈），其余交互只做hover/active状态过渡。不加page load入场动画、不加scroll trigger（固定窗口无滚动）
4. **Spatial Composition**：单列居中，竖窗比例约1:1.82。视觉重心在上部40%（杯子+数字），操作区在中下部（按钮），底部留适度留白收住。当前问题就是空间分配失衡，本方案的核心改动
5. **Background**：暖奶油纯色`#FBF7F0`，项目现状已定。杯子区自带沙色椭圆阴影和水蓝渐变提供视觉层次，背景本身不加纹理

## 3. 信息层级方案

### 第一层级（用户瞟一眼就看到的）

- **杯子插画**：视觉焦点，带水位和波浪动画
- **ml数字**：48px / 700 / `#3D342E`

这两个元素组成视觉中心，位于页面上部40%区域。用户打开面板，第一眼看到杯子水位和数字，3秒内知道今天喝了多少。

### 第二层级（支撑核心的上下文和操作）

- **主按钮**：15px / 600 / 白字蓝底，页面唯一高饱和色块
- **进度条**：260px横向轨道+3节点，提供达标进程的空间参照
- **状态文字**：14px / 400 / `#7A6E62`，给出目标/差额/达标信息

### 第三层级（辅助信息和次要操作）

- **副操作行**：13px / 500 / `#3D342E`底`#F2ECE1`，3个药丸，提供快速记录非标准量
- **撤销按钮**：13px / 400 / `#7A6E62`带边框，次要纠错操作
- **下次时间**：13px / 400 / `#7A6E62`，辅助信息
- **顶部栏**：标题+日期+功能入口，12-16px / `#3D342E`和`#7A6E62`

## 4. 布局结构

### 核心改动

| 改动项 | 当前值 | 新值 | 原因 |
|--------|--------|------|------|
| 杯子SVG width属性 | 105 | 80 | 渲染高度从174px降到133px，释放41px给其余区域 |
| ml数字字号 | 54px | 48px | 配合缩小的杯子，保持视觉比例协调 |
| 主按钮宽度 | 220px | 260px | 与进度条同宽，形成视觉对齐柱；更大点击区域 |
| 主按钮高度 | 42px | 46px | 更舒适的点击目标 |
| 副按钮高度 | 34px | 36px | 略增触控舒适度 |
| 节间距 | 3-14px | 12-32px | 解决挤在一起的问题 |
| 底部空白 | ~110px | 41px | 解决下半部大片空白 |

### 垂直节奏说明

页面分成三个视觉组，用大间距隔开：

- **视觉组**（y=76-291）：杯子+数字+状态文字，组内间距紧凑（4-12px），作为一个整体传达进度

## 5. 组件规格清单

### A. 顶部栏

- **复用**：沿用现有组件，不改结构
- **尺寸**：高44px（padding 14px 16px 4px），全宽340px
- **布局**：flex / align-items:center / justify-content:space-between
- **左侧**：水豚头像SVG 26x26 + 间距8px + 文字"今天" 16px/600/`#3D342E`
- **右侧**：日期文字 12px/400/`#7A6E62` + 间距6px + 桌宠按钮(.ic 26x26) + 齿轮按钮(.ic 26x26) + 关闭按钮(.ic 26x26)，按钮间距2px
- **拖拽区**：整个顶部栏带`data-tauri-drag-region`

**四态**：

| 状态 | 顶部栏整体 | 图标按钮(.ic) |
|------|-----------|--------------|
| 默认 | 静态 | 图标色`#9A8E7E`，无底色 |
| hover | - | 底色`#F0E8DA`，150ms过渡 |
| active | - | 底色`#E9E1D3` |
| disabled | 不适用 | 不适用 |

### B. 杯子插画

- **复用**：沿用现有SVG组件，只改渲染尺寸
- **viewBox**：`0 0 140 232`（不变）
- **width属性**：80（从105改为80）
- **渲染尺寸**：80x133px
- **定位**：`#cupwrap`水平居中，margin-top: 32px（从当前6px改为32px）
- **内容不变**：玻璃杯身、水位渐变（`#7FCEF0`到`#3AA7E0`）、双层水面波浪、柠檬片、吸管、底部沙色椭圆阴影、杯壁高光条

**视觉态**：

| 状态 | 触发 | 视觉 |
|------|------|------|
| 进行中 | 总量<目标 | 水位按比例填充，波浪常态晃动 |
| 达标 | 总量>=目标 | 杯子描边色切成`#2FB07C`，水位满 |

超长文本：不适用（纯图形组件）。

### C. 数字显示（#numwrap）

- **复用**：沿用现有组件，调整字号
- **定位**：text-align:center，margin-top:12px（从当前4px改为12px）
- **主数字（#num）**：48px / 700 / `#3D342E` / display:inline / line-height:1（从当前54px改为48px）
- **单位（#unit）**：18px / 500 / `#9A8E7E` / margin-left:2px / display:inline（从当前20px改为18px）
- **块高度**：约48px（由主数字line-height决定）
- **内容约束**：数字范围0-5000+，最宽情况"5000"约106px宽，加"ml"约130px，在340px居中无溢出风险

**四态**：纯展示组件，无交互态。数字变化动效：数值更新时无特殊动画（保持现状的直接替换）。如需加入弹跳动效，见第6节动效规范。

### D. 状态文字（#sub）

- **复用**：沿用现有组件，调整间距
- **定位**：text-align:center，margin-top:4px（不变）
- **字号**：14px / 400 / `#7A6E62`
- **行高**：1.4

**三种内容态**：

| 条件 | 文案 | 样式 |
|------|------|------|
| 首次打开未喝 | "目标2000ml" | 14px / `#7A6E62` |

## 7. 设计依据

### 杯子从width=105缩到80

当前杯子渲染高度174px，占窗口高度28%。在340px宽窗里，105px宽的杯子占宽度31%，视觉比重过大，把所有注意力吸走，按钮区被压缩到紧贴下方。缩到80px后渲染高度133px（占21%），释放41px给其余元素的间距，杯子仍是最大的单体图形，但不再喧宾夺主。

### 数字从54px降到48px

杯子缩小后，54px数字与133px杯子的比例（54/133=0.41）偏大，数字视觉权重几乎追平杯子。降到48px后比例（48/133=0.36）更协调，数字仍然是第一层级元素。

### 主按钮加宽到260px

当前220px按钮在340px窗口中偏窄（65%），与上方260px进度条不对齐。加宽到260px后：①与进度条形成对齐柱，视觉更整洁；②点击区域从220x42增大到260x46，操作更舒适；③蓝色面积略增，强化了操作区的视觉存在感。

### 间距重分配策略

当前主要问题是组间间距过小（4-14px）导致内容挤成一团。新方案用三级间距：
- 4-12px：组内元素（数字到状态、进度条到标签），表达紧密关联
- 14-20px：操作组内元素（主按钮到副按钮、副按钮到撤销），表达功能分组
- 26-32px：组间分隔（视觉组到进度组、进度组到操作组），表达逻辑分段

底部41px留白与顶部栏44px接近，上下对称收住页面边界。

### 不改色彩、不改组件结构

这次重设计只解决空间分配问题，不改配色、不改组件数量、不改交互流程。项目配色和组件都在v2设计文档里经过完整审美判断和工程底线校验，没有理由在布局调整时顺手改掉。
